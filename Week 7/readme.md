# Week 7 Skill – Next-Token Probabilities: Logits and Top-K Candidates

## Overview
This skill focuses on understanding how a language model predicts the next token. Using a pretrained DistilGPT-2 model with Hugging Face Transformers, the experiment extracts logits, converts them into probabilities using the Softmax function, and identifies the top-K most probable next-token candidates.

## Objectives
- Understand the concept of next-token prediction in language models.
- Inspect logits generated by a pretrained language model.
- Understand how logits are converted into probabilities using Softmax.
- Extract the top-K next-token candidates.
- Display token IDs, token text, and corresponding probabilities.
- Identify the most probable next token based on its probability.

## Model Used
**DistilGPT-2**

DistilGPT-2 is a smaller pretrained language model used to inspect next-token predictions and probability distributions.

## Implementation
1. Install the required Python libraries using `requirements.txt`.
2. Import PyTorch and the required classes from Hugging Face Transformers.
3. Load the pretrained DistilGPT-2 tokenizer and model.
4. Define an input prompt: "The capital of France is".
5. Convert the input prompt into token IDs using the tokenizer.
6. Pass the input tokens through the model to obtain logits.
7. Extract the logits corresponding to the final input position.
8. Apply the Softmax function to convert logits into probabilities.
9. Use Top-K selection to identify the five candidates with the highest probabilities.
10. Display the candidate tokens, token IDs, and probability values.
11. Identify and display the most probable next token.

## Execution

Install the dependencies:

```bash
python -m pip install -r requirements.txt
```

Run the Python program:

```bash

```

The program loads DistilGPT-2, processes the input prompt, calculates next-token probabilities, and displays the top five candidates in the terminal.
